## Discrepancies / things to clarify

### A. Who validates — "Direction" vs "RH" (HR)?
- thomas.md:114 — "direction … only can accept or refuse the project"
- tiziano.md:156 — "Seul les RH peuvent valider et refuser les projets. Ou suspendre."

> Thomas attributes validation to the **direction**, Tiziano to **RH (HR)**. Need to confirm whether these are the same body or two distinct roles.

### B. Multiple roles — allowed or not?
- thomas.md:118 — "people can have multiple roles"
- tiziano.md:164 — "Personne peut avoir plusieurs rôles."

people can have multiple roles, like a person can propose a project and also be a director

> Ambiguous: Tiziano's "Personne" can mean *"a person"* (agrees with Thomas) **or** *"nobody"* (contradicts Thomas). This directly affects the permissions model — **must be confirmed with the client.**

### C. "Suspend" as a third direction action
- tiziano.md:156 / tiziano.md:160 — direction/RH can also **suspend** projects
- thomas.md only mentions accept / refuse (+ ask for review)

> Tiziano records a "suspend" state (linked to the review system, tiziano.md:76) that Thomas doesn't explicitly list. Worth modeling as a status.

### D. Budget % entry — manual vs automatic (open question, only in Thomas)
- thomas.md:129-131 — should the 20% / budget share be entered manually, or auto-detected via a form / payment system?
- Not addressed in tiziano.md.

> Still an **open question** for the client; no email/payment system decision yet (thomas.md:7).

## Summary

The two note sets are **highly consistent** — they describe the same 4-module
tracking app with the same lifecycle:

```
Proposition  ->  Direction  ->  Récolte  ->  En cours
 (anyone)        (accept/        (collect      (track +
                 refuse/         ≥80% res.)    comments)
                 suspend)
   |                |               |              |
   +----------------+---------------+--------------+--> Archives (per stage)
                  "le frigo" = refused archive
```

Both confirm: tracking-only (not management), portfolio view, impact matrix,
the "frigo" archive, the 80% green threshold, age-based color coding
(orange/red/auto-archive), email escalation in "En cours", per-stage archives,
lead ≠ initiator, and a sober design.

**Open / conflicting points to resolve with the client:** validator identity
(Direction vs RH), whether multiple roles per person are allowed, the explicit
"suspend" state, and manual-vs-automatic budget entry.
